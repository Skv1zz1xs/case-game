# Кейс-Рояль

Браузерный симулятор открытия кейсов для компании друзей. Только виртуальные монеты, без реальных денег и доната.

## Команды
- `npm ci`: установить зависимости
- `npm run dev`: сервер разработки (открывается и с телефона в той же сети)
- `npm test`: юнит-тесты (RTP кейсов, фри кейс, апгрейдер, контракты)
- `npm run sim`: симуляция баланса (`-- --n 6000 --bonus`)
- `npm run build`: сборка в `dist/` (статика для GitHub Pages / Vercel)

## Устройство
- `src/config/economy.ts`: **все цифры экономики**
- `src/data/`: темы кейсов, модели оружия, генерация кейсов под RTP
- `src/core/`: логика без React (ГСЧ с seed, выпадение, износ/StatTrak/паттерны, апгрейд, контракты, состояние игрока)
- `src/ui/`: React-интерфейс, SVG-скины, лента, анимации дропа, звук (WebAudio)
- `scripts/balance-sim.ts`: симуляция 2-часовых сессий

## Этапы
1. ✅ Ядро: кейсы, инвентарь, экономика, бонусы
2. ✅ Апгрейдер (колесо) и контракты с книгой секретных рецептов
3. Онлайн (Firebase)
4. Батлы
5. Батл-пасс, достижения, остальное
